# 📚 Gyanu Notes

Free study notes & past exam papers for Class 8–12 students in Nepal (NEB / SEE aligned).

Status: In active development. Not yet production-ready.


## ✨ Features
- Class-wise & subject-wise notes
- Past papers & model papers
- Search & bookmarks
- User dashboard & history
- Admin content management

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- Firebase Hosting, Firestore, Auth, Cloud Functions

## 🚀 Getting Started
```bash
# Serve locally
npx serve .

# Run Firestore rules tests
npm run test:rules
```

## 📦 Deploy
```bash
npm run deploy
```
